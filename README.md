# Applsci-4644581 — Supplementary Data & Materials

All data and supplementary materials for the manuscript are organized as follows.

## Data archives (ZIP, each < 100 MB)
| File | Contents |
|---|---|
| datasets_roads_geom.zip | roads.shp geometry (LZMA) |
| datasets_roads_attr.zip | roads attribute tables (.dbf/.shx/.prj) |
| datasets_basic_other.zip | buildings, rivers, railways, POIs, traffic, natural, protected, boundaries (Sichuan/Ya'an), waterways, places |
| datasets_landuse.zip | landuse shapefile |
| datasets_dem.zip | 30 m DEM (Yaan.tif, 75 MB) |
| datasets_population.zip | LandScan Global 2024 population raster |
| datasets_population_preview.zip | LandScan colorized preview + metadata |
| datasets_fault_history.zip | active-fault traces + historical earthquake catalog |

## Supplementary materials (uncompressed)
supplementary/ — pipeline & metrics, prompt templates, query-set partition, graph artefact, runs statistics & bootstrap CIs, annotation protocol, AHP weights, provenance logs, hybrid baseline, sensitivity analysis, expert map evaluation, cache reliability, summary audit.

Note: datasets_roads_geom.zip uses LZMA; unpack with 7-Zip, WinRAR, or any modern unzipper.
